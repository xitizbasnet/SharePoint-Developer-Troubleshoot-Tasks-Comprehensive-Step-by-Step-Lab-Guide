# LAB 03 — News, Events & Media

## 🎯 Objective

Share company news, create events, display weather, countdown timers, PowerPoint slides, and embed YouTube/Stream videos.

## 📋 Prerequisites

* SharePoint Communication or Team site
* Site Owner/Member permissions
* Microsoft 365 subscription

---

## Task 3.1 — Share News on a SharePoint Site

### 1. Create a News post

On your site home page → **+ New** → **News post** → choose a layout (**Blank, Visual, Side-by-side**).

### 2. Add title, image & text

Write a compelling headline, upload a hero image, and add body content using web parts.

### 3. Publish & promote

Click **Post news** → the article appears in the **News** web part on the homepage.

### 4. Boost the News post

From the news article → **'...'** → **Boost news post** → set duration so it appears prominently.

---

## Task 3.2 — Create Events

### 1. Add an Events web part

Edit the page → **'+'** → search **'Events'** → configure: choose a list source (**Events list**).

### 2. Create an Events list

**Site Contents** → **+ New** → **List** → **Events list template** → add events with date/time/location.

### 3. Add calendar view

Inside the Events list → **+ Add view** → choose **Calendar view** → set date field → **Save**.

---

## Task 3.3 — Display Weather & Countdown Timer

### 1. Add Weather web part

Edit page → **'+'** → search **'Weather'** → select → configure your location → **Publish**.

### 2. Add Countdown Timer web part

Edit page → **'+'** → search **'Countdown timer'** → set the target date/time and label → **Publish**.

---

## Task 3.4 — Insert YouTube / Stream Videos & PowerPoint Slides

### 1. Embed a YouTube video

Edit page → **'+'** → **File viewer or Embed web part** → paste the YouTube embed iframe code.

### 2. Embed a Stream (SharePoint) video

Upload video to SharePoint/Stream → copy link → use **File viewer web part** → paste URL.

### 3. Display a PowerPoint slide

Edit page → **'+'** → **File viewer** → select a `.pptx` from your library → it renders inline.

---

## 💡 Best Practice Tips

* 📰 **Use the News web part on Hub sites:** Aggregate news from all connected sites automatically.
* 🖼️ **Compress hero images:** Keep hero images below **300 KB** for faster page load times.
* ♿ **Add alt text:** Add alt text to all media for accessibility and **WCAG 2.1** compliance.
* 🎥 **Use Microsoft Stream (SharePoint) for internal videos:** Keep internal corporate video content within your tenant instead of using YouTube.
* 📅 **Schedule news posts:** Use the **'Schedule'** toggle to publish news posts automatically at a future date.
