# LAB 13 — Lookbook, Learning Pathways & Organisation Asset Library

## 🎯 Objective

Install Microsoft Learning Pathways for free training, explore the SharePoint Look Book, and create an Organisation Asset Library.

## 📋 Prerequisites

* SharePoint Admin or Global Admin
* App Catalog configured
* Communication site available

---

## Task 13.1 — Install Learning Pathways

### 1. Open App Catalog

**SharePoint Admin Center → Apps → App Catalog**. If none exists, create one first.

### 2. Get the solution

Go to `aka.ms/learningpathways` → click **'Add to your tenant'** and sign in with admin account.

### 3. Provision the site

A new Communication site named **'Microsoft 365 Learning Pathways'** is provisioned automatically.

### 4. Customise playlists

Site admin can hide irrelevant M365 playlists and add custom company learning playlists.

### 5. Promote

Link to the Learning Pathways site from your Hub home page's **Quick Links** web part.

---

## Task 13.2 — Create an Organisation Asset Library

### 1. Create a dedicated site

Create a new Communication site (e.g., **'Brand Assets'**) to host company logos and images.

### 2. Upload approved assets

Create a **Document Library** → upload logos, brand images, icons, and approved templates.

### 3. Register as Org Asset Library

**SharePoint Admin Center → Settings → Organisation assets → + Add** → select the library URL.

### 4. Verify in Image Picker

Edit a SharePoint page → add an **Image** web part → click **'Your Organisation'** → your assets appear.

---

## 💡 Best Practice Tips

* 🔐 **Restrict the Organisation Asset Library:** Limit access to **Site Owners** only to prevent unapproved images from entering the library.
* 📁 **Organise assets by category:** Use folders such as **Logos, Banners, Icons, Templates**.
* 🔄 **Keep Learning Pathways current:** Learning Pathways content updates automatically when Microsoft updates its M365 training content.
* 📢 **Promote Learning Pathways:** Include Learning Pathways in your company newsletter and onboarding process to drive adoption.
