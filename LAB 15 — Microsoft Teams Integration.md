# LAB 15 — Microsoft Teams Integration

## 🎯 Objective

Add SharePoint document library tabs to Microsoft Teams channels for fast access and unified collaboration.

## 📋 Prerequisites

* Microsoft Teams
* SharePoint site connected to a Teams group
* Team Owner or Member permissions

---

## Task 15.1 — Add a SharePoint Library as a Tab in Teams

### 1. Open the Teams channel

In **Microsoft Teams** → go to the **Team and Channel** where you want to add the tab.

### 2. Add a tab

Click **'+' (Add a tab)** at the top of the channel → search **'SharePoint'** → select.

### 3. Choose the library

Select the **SharePoint site** → navigate to the **Document Library** you want to pin.

### 4. Name the tab

Give it a meaningful name (e.g., **'Project Docs'**, **'HR Policies'**) → click **Save**.

### 5. Access from Teams

The library now appears as a tab — files can be viewed, edited, and co-authored directly in Teams.

---

## Task 15.2 — Add a SharePoint Page as a Teams Tab

### 1. Copy the SharePoint page URL

Navigate to the SharePoint page → copy the URL from the browser.

### 2. Add Website tab in Teams

**Teams channel → '+' → Website** → paste the SharePoint page URL → name it → **Save**.

### 3. Test

The SharePoint page renders inside Teams, maintaining full web part functionality.

---

## 💡 Best Practice Tips

* 🔗 **Use the connected Team site:** When a Team is created, SharePoint automatically creates a connected team site — use this site's library for the tab.
* 🔄 **Remember the shared library:** File changes made in the Teams tab are reflected instantly in SharePoint (same library).
* 📌 **Keep channel tabs focused:** Pin the most used libraries as tabs — avoid clutter with more than **5 tabs per channel**.
* 📝 **Store meeting notes centrally:** Use Teams meeting notes stored in SharePoint for persistent, searchable meeting records.
* 🔐 **Manage granular permissions:** Grant permissions at the **SharePoint library level**, not Teams level, for granular access control.
