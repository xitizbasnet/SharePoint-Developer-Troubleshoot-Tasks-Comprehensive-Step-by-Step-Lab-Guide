# LAB 17 — Mobile & Offline Access

## 🎯 Objective

Use the SharePoint mobile app to create and access content on the go, and sync document libraries for offline editing.

## 📋 Prerequisites

* SharePoint Mobile App (iOS/Android)
* OneDrive sync client installed on PC/Mac
* SharePoint account

---

## Task 17.1 — Use the SharePoint Mobile App

### 1. Install the app

Download **'Microsoft SharePoint'** from the **Apple App Store** or **Google Play Store**.

### 2. Sign in

Open the app → sign in with your **Microsoft 365 account credentials** → allow required permissions.

### 3. Browse sites

Tap **'Sites'** → see your followed and recent sites. Tap to open.

### 4. Create and edit

Inside a library → tap **'+'** to upload files, create folders, or start a new Office document.

### 5. Follow sites

Tap the **star (⭐)** on any site to follow it — it appears on the mobile home screen for quick access.

---

## Task 17.2 — Sync a Document Library for Offline Access

### 1. Install OneDrive sync client

Download OneDrive from `microsoft.com/onedrive` → install → sign in with your M365 account.

### 2. Sync a library

Open the SharePoint library in a browser → click **Sync** in the toolbar.

### 3. OneDrive opens automatically

The library syncs to your local **File Explorer / Finder**. Work on files as if they were local.

### 4. Files go online automatically

When internet is restored, changes sync back to SharePoint automatically.

### 5. Manage sync

Right-click the **OneDrive icon** in the system tray → **Settings → Account** → to stop syncing a folder.

---

## 💡 Best Practice Tips

* 📱 **Follow critical sites:** Follow the most critical sites in the mobile app so they appear on the home screen for instant access.
* 💾 **Keep critical files offline:** Use **'Always keep on this device'** (right-click file in OneDrive) for files you need reliably offline.
* 📁 **Avoid syncing entire libraries:** Sync only the folders you need to conserve local disk space.
* 💬 **Report issues:** Report issues via the mobile app: **Me → Help & Feedback** — helps Microsoft improve the app.
